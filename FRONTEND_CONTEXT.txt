6. STATE MANAGEMENT - ZUSTAND
================================================================================

AUTH STORE (useAuthStore):
  State:
    - token: JWT auth token
    - user: Current authenticated user
    - isAuthenticated: Boolean flag
    - isLoading: Loading state during login
    - error: Error message

  Methods:
    - login(username, password): Authenticate user
    - logout(): Clear auth state
    - setToken(token): Update token
    - setUser(user): Update user
    - setError(error): Update error
    - hydrate(): Load from localStorage on app init

  Usage:
    const { user, login, logout, isAuthenticated } = useAuthStore();


7. API INTEGRATION
================================================================================

API CLIENT (Axios):
  - Base URL: http://localhost:8080
  - Auto-adds JWT token to all requests
  - Handles 401 errors (token expiration)
  - Returns typed responses

API ENDPOINTS IMPLEMENTED:
  Auth:
    - POST /auth/login
    - POST /auth/logout

  Users (Admin):
    - GET /admin/users
    - POST /admin/users
    - GET /admin/users/{id}
    - PUT /admin/users/{id}
    - DELETE /admin/users/{id}
    - POST /admin/users/{userId}/roles
    - DELETE /admin/users/{userId}/roles/{roleId}

  Roles (Admin):
    - GET /admin/roles
    - POST /admin/roles
    - GET /admin/roles/{id}
    - PUT /admin/roles/{id}
    - DELETE /admin/roles/{id}
    - POST /admin/roles/{roleId}/permissions
    - DELETE /admin/roles/{roleId}/permissions/{permissionId}

  Permissions (Admin):
    - GET /admin/permissions
    - POST /admin/permissions
    - GET /admin/permissions/{id}
    - PUT /admin/permissions/{id}
    - DELETE /admin/permissions/{id}

  Partners:
    - GET /v1/read/partners
    - POST /v1/create/partners
    - GET /getpartner/{id}
    - PUT /v1/update/partners

  Transfers:
    - GET /v1/read/transfers
    - POST /v1/create/transfers
    - GET /gealltransfers/{partnerId}

10. AUTHENTICATION FLOW
================================================================================

LOGIN FLOW:
  1. User enters username + password on LoginPage
  2. Click "Sign In" button
  3. API call: POST /auth/login with credentials
  4. On success:
     - Store JWT token in localStorage
     - Store user object in localStorage
     - Update Zustand auth store
     - Redirect to Dashboard
  5. On error:
     - Display error message
     - Token stays in localStorage for retry

PROTECTED ROUTES:
  - All routes except /login require isAuthenticated = true
  - PrivateRoute component checks auth state
  - Auto-redirect to /login if not authenticated

TOKEN MANAGEMENT:
  - JWT sent in: Authorization: Bearer <token>
  - Added by Axios interceptor
  - Persisted in localStorage
  - Loaded on app init via hydrate()

LOGOUT:
  - Clear Zustand state
  - Remove localStorage data
  - Redirect to login page

17. DEVELOPMENT GUIDELINES
================================================================================

NAMING CONVENTIONS:
  - Components: PascalCase (LoginPage.tsx)
  - Files: Match component name
  - Functions: camelCase (handleClick)
  - Constants: UPPER_SNAKE_CASE (API_BASE_URL)
  - Types: PascalCase (User, ApiResponse)

CODE ORGANIZATION:
  - One component per file
  - Group related imports
  - Export at bottom of file
  - Use TypeScript strict mode
  - Type all function parameters

BEST PRACTICES:
  - Use hooks for state management
  - Prefer functional components
  - Keep components small and focused
  - Prop drilling minimized with Zustand
  - Comments for complex logic
  - Error boundaries for error handling
