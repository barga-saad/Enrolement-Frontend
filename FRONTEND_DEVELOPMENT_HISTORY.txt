1.7 STATE MANAGEMENT - ZUSTAND
─────────────────────────────────

AUTH STORE (useAuthStore):
  State:
    - token: JWT token (string | null)
    - user: User object (User | null)
    - isAuthenticated: boolean
    - isLoading: boolean (during login)
    - error: string | null

  Methods:
    - login(username, password): Authenticate
    - logout(): Clear state
    - setToken(token): Update token
    - setUser(user): Update user
    - setError(error): Update error
    - hydrate(): Load from localStorage on init

  Usage:
    const { user, login, logout } = useAuthStore();
    On app load: auth.hydrate() called in useAuth hook

  Storage:
    - localStorage keys: "authToken", "user"
    - Persists across page reloads
    - Cleared on logout


1.8 API CLIENT SETUP
──────────────────────

AXIOS CONFIGURATION:
  Base URL: http://localhost:8080
  Timeout: 30 seconds
  Default headers: Content-Type: application/json

REQUEST INTERCEPTOR:
  - Extracts JWT from localStorage
  - Adds to all requests: Authorization: Bearer <token>
  - Transparent to application code

RESPONSE INTERCEPTOR:
  - Catches 401 errors (token expiration)
  - Auto-logout user
  - Redirect to login page
  - Prevents stuck state

API METHODS IMPLEMENTED:
  Auth:
    - login(username, password) → LoginResponse
    - logout()

  Users:
    - getUsers(), getUser(id), createUser(data)
    - updateUser(id, data), deleteUser(id)
    - assignRoleToUser(userId, roleId)
    - revokeRoleFromUser(userId, roleId)
    - getUserRoles(userId)

  Roles:
    - getRoles(), getRole(id), createRole(data)
    - updateRole(id, data), deleteRole(id)
    - getRolePermissions(roleId)
    - assignPermissionToRole(roleId, permissionId)
    - removePermissionFromRole(roleId, permissionId)

  Permissions:
    - getPermissions(), getPermission(id)
    - createPermission(data), updatePermission(id, data)
    - deletePermission(id), getOwnerCheckPermissions()

  Partners:
    - getPartners(), getPartner(id), createPartner(data)
    - updatePartner(id, data), deletePartner(id)

  Transfers:
    - getTransfers(), createTransfer(data)
    - getPartnerTransfers(partnerId)
    - updateTransfer(id, data), deleteTransfer(id)

1.10 CUSTOM HOOKS
───────────────────

useAuth():
  - Accesses: token, user, isAuthenticated, isLoading, error
  - Methods: login(), logout(), setError()
  - Auto-hydrates on component load
  - Used in PrivateRoute and components needing auth

useWindowSize():
  - Returns: { width, height }
  - Updates on window resize
  - Used for responsive behavior

useIsMobile():
  - Returns: boolean (true if width < 768px)
  - Updates on resize
  - Used to control sidebar visibility

usePrevious<T>():
  - Returns: Previous value of prop/state
  - Used for comparisons and side effects
